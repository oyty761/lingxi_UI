# 灵小犀前端开发交接说明

> 更新日期：2026-08-17
> 当前需求基线：`中文儿童叙事能力干预系统框架-流程.pdf`

## 1. 项目定位

当前项目是纯 HTML、CSS、JavaScript 的第一阶段交互原型，不依赖框架或构建工具。页面数据暂存在各页面脚本中，刷新后恢复为演示数据。

旧 Demo 只用于参考设计语言，不是功能依据。后续出现需求冲突时，优先级为：甲方最新确认 > 最新 PDF > `docs/需求基线与页面流程.md` > 旧 Demo。

## 2. 页面与入口

```text
pages/
├─ login.html             登录页
├─ index.html             工作台：九类业务入口、概览、IEP 路径、最近个案与快捷操作
├─ case-database.html     个案数据库：个案基本情况和干预小组
├─ case-detail.html       个案数据平台与课次记录
├─ course-database.html   课程中心：叙事课程、专业筛选、个案选课
└─ course-detail.html     叙事干预课堂：脚本、提问、显隐、录音与分析
```

入口为 `pages/index.html`，顶部导航固定为：工作台、个案数据库、课程中心。

## 3. 已实现的最新业务流程

### 工作台

- 保留欢迎区、四项数据概览、最近关注个案和快捷操作的设计内容。
- 移除旧版“安排日程”中心逻辑。
- 展示 PDF 第一阶段的九类业务入口：叙事评估、叙事干预、语音意识训练、语用评估、社交技能干预、听处理能力训练、读写技能筛查、字理干预、语义网络训练。
- 展示叙事干预 IEP 路径：分析结果 → 推荐课程 → 课程选择 → 生成并推送个案。
- 当前深度实现叙事评估/干预入口；其余第一阶段模块保留入口并提供明确反馈。

### 个案到上课

- `case-database.html` 的“上课”和 `case-detail.html` 的“开始上课”均跳转课程中心。
- 跳转携带 `mode=select`、`case`、`caseName`，课程中心显示当前选课个案。
- 选择课程后继续携带个案信息进入叙事干预课堂。
- 工作台“开始上课”先进入个案数据库，符合“先选个案、再选课程”的流程。

示例：

```text
course-database.html?mode=select&case=1&caseName=2b
course-detail.html?id=1&name=小明的新自行车&case=1&caseName=2b
```

### 课程中心

- 课程项目改为故事型叙事评估/干预课程，数据包含故事主题、核心问题、结局、教学目标和课堂功能。
- 筛选项适配当前课程特性：业务模块、教学目标、课堂功能和故事主题。
- 支持关键词与组合筛选、结果统计、无结果与重置状态。
- 新增课程、导入课程只保留入口，并明确标记“待确认”；未擅自设计字段或导入规则。

### 叙事干预课堂

- 故事画面提供横版翻页和竖版滚动两种排列；每一页只包含一幅图及其对应文段。
- 横版在文段下方提供上一幅/下一幅按钮；竖版通过滚轮或触控上下浏览。
- 进入“提问与回答”时自动折叠故事画面，提问区占用主要屏幕空间；可随时重新展开画面。
- 播放脚本：自动顺序播放、手动点击单图播放、语音与图片对应。
- 提问与回答：故事语法/故事理解两类问题，支持顺序和随机提问。
- 图片出现/消失：支持全部和单幅控制。
- 图标出现/消失：图标对应人物、问题、感受、行动和结局。
- 个人讲述录音：原型提供录音计时、文本转录、自动注音示例、文本存档和语言样本分析结果。

## 4. 设计与代码约束

- 全站颜色、字号、间距、圆角和阴影来自 `css/tokens.css`。
- 共享组件来自 `css/components.css`，页面特有样式保留在对应 HTML 中。
- 保持浅灰背景、白色卡片、低饱和蓝绿黄点缀，不使用强商务风。
- 所有入口必须有跳转或结果反馈，不保留点击后无反应的按钮。
- 页面需适配桌面、平板和手机，不出现横向溢出。
- 后续接入接口时，优先替换页面脚本中的数据数组和渲染函数，不重做 DOM 结构。

- 工作台九个入口是否都有正确跳转或反馈。
- 个案列表/详情“上课”是否进入带个案信息的课程中心。
- 课程筛选、选课和进入课堂是否保持个案参数。
- 自动/手动脚本、两类提问、图片/图标显隐、录音与分析是否可操作。
- 1280px、平板和手机宽度下是否无内容遮挡或横向溢出。
- `docs/需求基线与页面流程.md` 是否随新增确认结论同步更新。
